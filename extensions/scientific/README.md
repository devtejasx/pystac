# pystac-ext-scientific

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Scientific Citation Extension](https://github.com/stac-extensions/scientific).
This extension provides fields for linking STAC items and collections to scientific publications, including DOIs and bibliographic citations.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/scientific/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension specification it targets.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers), so the PATCH number can differ from the extension's, e.g. `1.0.1` still targets v1.0.0.
