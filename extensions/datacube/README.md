# pystac-ext-datacube

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Datacube Extension](https://github.com/stac-extensions/datacube).
This extension describes datasets that are organized as multi-dimensional datacubes, including dimension types, extents, values, and reference systems.

## Supported versions

- [v2.2.0](https://stac-extensions.github.io/datacube/v2.2.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension specification it targets.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers), so the PATCH number can differ from the extension's, e.g. `2.2.1` still targets v2.2.0.
